## 📺 YouTube Clone (HTML Only)

This project is a simple **YouTube homepage clone** built using **pure HTML**. It's designed to mimic the layout and structure of the YouTube main page for practice and educational purposes. No CSS or JavaScript is included in this version.

### 🔧 Features:
- YouTube-like structure using semantic HTML5 elements
- Navbar with logo, search bar, and icons
- Sidebar menu layout
- Video thumbnails and titles
- Channel information layout

### 🛠️ Technologies Used:
- HTML5

### 📚 Purpose:
This project is created for learning and practicing HTML layout skills. It's a great starting point for beginners looking to understand how real-world websites are structured.
